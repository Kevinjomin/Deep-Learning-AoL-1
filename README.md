Deep Learning project for melanoma classification using ISIC datasets and ResNet models.

---

### Project content

* **`sourceCode.ipynb`**
  Jupyter Notebook containing all code.

* **`isic_2018_dataset/`**
  Includes image files and metadata CSV for the ISIC 2018 dataset

* **`isic_2019_dataset/`**
  Includes image files and metadata CSV for the ISIC 2019 dataset

* **`augmented_dataset/`**
  Contains images generated by applying random transformation to the minority class in the ISIC 2018 training dataset.

* **`logs_base_dataset/`**
  TensorBoard logs for hyperparameter tuning using the augmented dataset scenario.

* **`logs_combined_dataset/`**
  TensorBoard logs for hyperparameter tuning using the combined dataset scenario.

---

## How to Run

1. Open the `sourceCode.ipynb` notebook.
2. Select a Python kernel / virtual environment (Note: Python 3.14.0 was used)
3. Run the code (library installations are contained in the notebook).
